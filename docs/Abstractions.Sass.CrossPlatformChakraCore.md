## Cross platform ChakraCore Package
This package bundles [DartSassHost by Taritsyn](https://github.com/Taritsyn/DartSassHost) and [JavaScriptEngineSwitcher.ChakraCore](https://github.com/Taritsyn/JavaScriptEngineSwitcher) with the native ChakraCore libraries for Windows, Linux and macOS (x64), so that `dart-sass` can run on any of them.

To install for cross-platform use, simply add the package reference.
